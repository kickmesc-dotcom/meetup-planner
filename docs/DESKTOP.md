# Широкий экран на ПК и вход по ссылке

Короткий ответ на вопрос «как научить Телеграм раскрывать мини-апп»: **никак не
заставить, но можно попросить и подстроиться**. Ниже — что реально умеет
платформа, что сделано в приложении и как этим пользоваться.

## 1. Что умеет Telegram

| Способ | Что происходит | Ограничение |
| --- | --- | --- |
| Мини-апп в окне Telegram Desktop | Открывается окно; ширину пользователь задаёт сам, клиент запоминает размер | Программно размер окна не задаётся — такого API нет |
| `WebApp.requestFullscreen()` | Просит клиент развернуть мини-апп на весь экран (Bot API 8.0) | Поддержка зависит от версии клиента; на части сборок Desktop страница занимает весь вьюпорт, но окно не растягивается |
| Прямая ссылка на Pages | Обычный сайт в браузере, любой размер, закладки, второй монитор | Нет `initData` — Telegram не подтверждает личность, нужен свой вход |

Вывод: надёжного «развернись на весь экран» не существует. Поэтому приложение
не полагается на fullscreen, а **выглядит как дэшборд на любом широком
вьюпорте**.

## 2. Что сделано

### Каркас (≥1024px)

- Постоянный **сайдбар** 256px: разделы по смыслу — «Смена» (события, задачи,
  чек-лист, табель, материалы), «Команда» (команда, приёмка, отчёт, проблемы,
  передачи), «Сервис» (календарь, встречи, стандарты, ссылки, профиль) и
  «Управление» (админка — только полному админу).
- Нижняя полоса на десктопе **не рисуется**: она осталась мобильной навигацией.
- Рабочая область — до 1360px, по центру. Внизу сайдбара — кто вошёл (имя,
  должность) и переключатель темы.
- Сужение окна меньше 1024px мгновенно возвращает мобильный вид: это один и
  тот же интерфейс, а не две разные сборки.

### Сводка смены

Справа от «Событий» — рельс: прогресс чек-листа, открытые и просроченные
поручения, открытые проблемы и быстрые переходы. Данные берутся теми же
запросами, что «Мои задачи» (общий кеш), новых ручек нет.

### Широкие экраны

- «Мои задачи» — карточки в две колонки (от 1280px).
- Профиль — две колонки: личные данные и прогресс рядом с разделами.
- Модальные листы и онбординг остаются узкими: это формы, а не страницы.

### Fullscreen

На широком вьюпорте при старте вызывается `requestFullscreen()` (Bot API 8.0).
Если клиент не поддерживает — молча живём в обычном окне. Телефон не трогаем:
там уже `expand()`.

## 3. Вход по ссылке (браузер)

Внутри Telegram личность подтверждает подписанный `initData`. В браузере его
нет, поэтому сервер выдаёт **личную ссылку доступа**.

### Как получить

1. В боте: команда `/app` → кнопка «Открыть на компьютере».
2. В приложении: профиль → «Веб-версия» → «Создать ссылку для компьютера».

Ссылка выглядит так: `https://<pages>/?access=sweb_…`. Открывается один раз;
приложение сохраняет токен в `localStorage` и **сразу вычищает `access` из
адресной строки** — токен не оседает в истории, закладках и логах прокси.

### Как это защищено

- В базе лежит только SHA-256 токена (`app_access_links.token_hash`): дамп БД
  не даёт входа.
- Срок — 30 дней. У одного человека не больше 5 живых ссылок: выпуск шестой
  отзывает самую старую.
- Отзыв — в профиле, раздел «Веб-версия» (и «Выйти из веб-версии на этом
  устройстве»). В списке видно, когда ссылку использовали последний раз: если
  это было не вы — отзывайте.
- Выпуск и отзыв разрешены **только с `initData`** (то есть из Telegram).
  Украденный токен не может продлить сам себя.
- Внутри Telegram `initData` всегда главнее локального токена: открыли мини-апп
  с ноутбука — работаете как владелец Telegram-аккаунта, а не как «кто-то из
  localStorage».

### Что делать, если устройство потеряно

Профиль → «Веб-версия» → у нужной ссылки «Отозвать». Браузер на потерянном
устройстве получит 401 при следующем запросе и покажет «Нужен вход». Выпускать
новую ссылку для остальных устройств не нужно — они продолжат работать.

## 4. Диагностика

| Симптом | Причина | Что делать |
| --- | --- | --- |
| `/app` отвечает «Сначала открой приложение кнопкой меню» | Профиля ещё нет в базе | Открыть мини-апп один раз, затем повторить `/app` |
| Браузер пишет «Нужен вход» | Ссылка отозвана/истекла, либо открыт голый адрес Pages | Взять новую ссылку командой `/app` |
| В профиле нет карточки «Веб-версия» | Бэкенд старше фронтенда (ручка отвечает 404) | Пересобрать бэкенд (`alembic upgrade head` + рестарт) |
| На ПК всё ещё узкая колонка | Окно мини-аппа меньше 1024px | Растянуть окно или открыть ссылку в браузере |
| `/app` в группе отвечает «пришлю в личку» | Ссылка = пароль, в общий чат не отправляем | Написать боту в личку |

## 5. Что проверять при правках вёрстки

- 360px: нижняя полоса, одна колонка, ничего не обрезано.
- 1024px: сайдбар появился, нижняя полоса исчезла, контент не липнет к краям.
- 1440px: рельс сводки на месте, карточки задач в две колонки.
- 1920px: контент не растягивается шире 1360px.
- Вход по `?access=`: адрес после загрузки без `access`, `localStorage` содержит
  `semitask.access_token`, запросы идут с `X-Access-Token`.
