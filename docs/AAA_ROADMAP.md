# Путь до ААА-уровня

Дата: 08.11.2026. Основание — факты репозитория и боевого контура на эту дату,
а не общие пожелания. «ААА» здесь — не сертификат, а измеримый уровень:
продукт не ломается, объясняет себя, работает на слабом телефоне и в плохой
сети, доступен с клавиатуры и скринридера, и его можно менять без страха.

Связанные документы: `UX_SKILL_AUDIT.md` (матрица 120 правил),
`UX_REORG_PLAN.md` (журнал этапов), `PERF_AUDIT.md`, `VISUAL_AUDIT.md`,
`AUDIT_SECURITY_STABILITY.md`, `MONITORING.md`, `CI.md`, `PRIVACY.md`.

## 3. Этапы

Порядок не случайный: сначала убираем то, что портит прод прямо сейчас,
потом строим автоматику, которая не даст откатиться, и только затем полируем.
Оценка — инженерные дни одного разработчика (1 день ≈ 6 часов).

### Этап 0. Чистый прод (0,5–1 день, P0)

- [x] `vite.config.ts`: `sourcemap: false` для прод-сборки (карты — артефакт CI,
      не публичный файл). Альтернатива — `hidden` + вырезание `.map` перед
      `wrangler pages deploy`.
- [x] Проверить после деплоя: `dist` 1,5 МБ, локально 0 `.map`, новые деплои карт не содержат.
- [ ] Удалить прошлые деплои в панели Pages (владелец): Cloudflare хранит ассеты старых деплоев, поэтому ранее опубликованные карты продолжают отдаваться по своим URL.
- [x] Убрать мёртвый HF Space из `DEPLOY_CLOUDFLARE.md` и подсказок в коде,
      оставить один боевой адрес API.
- [x] Зафиксировать в `_headers` запрет индексации служебных путей (если ещё нет).

**DoD:** в проде нет `.map`; документация называет один API; прод 200; запись в
`UX_REORG_PLAN.md` с ID сборки.

### Этап 1. Инженерный фундамент (4–6 дней, P0)

- [x] `eslint.config.js` (flat config, `@typescript-eslint`, `react-hooks`),
      `npm run lint` зелёный; добавить шаг в `ci.yml`.
- [x] `vitest --coverage` в CI с порогами: глобально 60 %, features 55 %, api 35 % —
      защита от регрессии. Цель 60/80 пока не достигнута (факт 59,4 / 39,3);
      тесты на `src/api/**` — следующий пакет.

- [x] Playwright: 6 сценариев на мокнутом API — вход, обязательность полей,
      отказ сервера, восстановление пароля, смена языка, мобильная ширина.
      До 8 осталось: кабинет, профиль и офлайн-старт — нужен демо-стенд с
      данными, без боевой базы.
- [x] Бюджет бандла: `scripts/check-bundle.mjs` проверяет главный чанк (raw/gzip),
      сумму js/css и отсутствие `.map`; шаг `Bundle budget` в CI; падение CI
      при превышении.
- [x] `ErrorBoundary` на уровне оболочки: ошибка рендера даёт понятный экран

## 4. Что требуется от владельца

Без этих действий этапы не закрыть полностью:

1. **Аккаунт владельца с демо-организацией** — иначе внутренние экраны
   проверяются только сборкой, а не глазами.
2. **Branch protection** в GitHub (Settings → Branches) — код готов, право нужно.
3. **Тариф Amvera 1 ГБ** — размен S-19 (безопасность зависимостей против памяти).
4. **Носитель узбекского** — вычитка ~70 сообщений и подписей.
5. **Участники usability-теста** (5 человек, 30–40 минут каждый).
6. **Решение по домену и платёжному провайдеру** — вне текущего плана, но
7. **Удалить прошлые деплои Pages** — на них лежат опубликованные source maps; снять их с публичного адреса можно только удалением деплоев или переездом на свой домен.
   блокирует публичный запуск.

## 5. Риски

| Риск | Как снижаем |
| --- | --- |
| e2e на живом API флакует | отдельный стенд с детерминированными демо-данными, без боевой базы |
| Линт на 75k строк даст сотни ошибок | включать по правилам, а не всё сразу; `--max-warnings 0` после первого прохода |
| Скриншот-регрессия шумит на шрифтах | фиксированный контейнер, `deviceScaleFactor`, шрифты в образе |
| Переезд базы ломает прод | репетиция на копии, окно, откат по runbook |
| Погоня за ⚠️ ради цифры | каждое «—» с причиной; правило без причины не закрывается |
| Сжатие API недоступно на Amvera | проверить до этапа 4; если нет — сжимать в приложении (`GZipMiddleware`) |
